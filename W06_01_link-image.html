แบบฝึกปฏิบัติ: HTML Link และ Image

เรียนรู้การสร้างลิงก์และการแทรกรูปภาพด้วยแท็ก HTML
พร้อมตัวอย่างและการตกแต่งด้วย CSS

🔗 ตัวอย่างลิงค์ (Link Example)

ผลลัพธ์
ไปยังเว็บเซต์มหาวิทยาลัย เปิด google ในแทบใหม๋ 💌ส่งอีเมลถึงผู้สอน ← กลับไปยังหน้าแรก
โค้ด HTML
  1. <a href = "https://www.npru.ac.th" > เว็บไซต์มหาวิทยาลัย </a>
  2. <a href = "https://www.google.com" target = "_blank" > เปิด Google ในแท็บใหม่ </a>
  3. <a href="mailto:teacher@example.com">ส่งอีเมล</a>
  4. <a href="index.html">กลับหน้าแรก</a>

🖼️ ตัวอย่างรูปภาพ (Image Example)

ผลลัพธ์
โค้ด HTML
  1. <img src = "images/campus.jpg" alt = "ภาพมหาวิทยาลัย" width = "220" >
  2. <img src = "images/student.jpg" alt = "นักศึกษากำลังเรียน" width = "180" >
  3. <img src = "images/logo.png" alt = "โลโก้วิชา" height = "80" >

🎯 จุดประสงค์การเรียนรู้

1อธิบายการใช้งานแท็ก <a> เพื่อสร้างลิงก์ไปยังหน้าเว็บหรือแหล่งต่าง ๆ
2แทรกรูปภาพด้วยแท็ก <img> พร้อมกำหนดคุณสมบัติพื้นฐาน
3ตกแต่งลิงก์และรูปภาพด้วย CSS เพื่อความสวยงามและน่าใช้งาน
